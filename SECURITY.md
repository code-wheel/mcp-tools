# Security

## Report a problem

Please do not open a public issue for a security problem.

Report it in private on GitHub, with the "Report a vulnerability" button
on the Security tab:

https://github.com/code-wheel/mcp-tools/security/advisories/new

Say what you saw, on which version, and how to see it again.

MCP Tools has not opted into the security advisory coverage of
drupal.org, so the Drupal Security Team does not take reports for it.

## Which versions get fixes

The newest release. MCP Tools is in beta. A fix comes as a new release,
and its release notes say what was fixed.

## What the module does to limit a client

The README has it under "Security" and "Calls that ask first": scopes,
read-only mode, write limits, the audit log, what is never granted, and
the calls that are run only after a person said yes.
